Titanic Dataset - Exploratory Data Analysis (EDA)
Overview
This project presents an Exploratory Data Analysis (EDA) of the Titanic dataset using Python. 
The objective is to understand the dataset by performing statistical analysis, exploring data distributions, and visualizing key features that influence passenger survival. 
In addition to EDA, this project demonstrates the computation of several commonly used distance and dissimilarity measures in data science and machine learning.
Features
Loaded and explored the Titanic dataset
Examined dataset shape, column names, and data types
Generated descriptive statistical summaries
Identified missing values using dataset information
Visualized passenger survival distribution
Analyzed gender and passenger class distributions
Explored age and fare distributions using histograms
Calculated Euclidean Distance
Calculated Manhattan Distance
Calculated Minkowski Distance
Calculated Cosine Dissimilarity
Calculated Nominal Attribute Dissimilarity
Performed data visualization using Matplotlib and Seaborn
Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook / Google Colab
Learning Outcomes
This project helped in understanding:
Data loading and preprocessing
Exploratory Data Analysis (EDA)
Statistical summaries of datasets
Data visualization techniques
Numerical and categorical data analysis
Distance and similarity measures used in machine learning
Interpreting real-world datasets for data-driven insights
Conclusion
The Titanic dataset was successfully analyzed using various EDA techniques and visualizations to understand passenger characteristics and survival patterns.
The project also demonstrates the implementation of multiple distance and dissimilarity measures, providing a strong foundation for clustering, classification, recommendation systems, and other machine learning applications.
